## 🎯 Key Concepts Explained

### The "Mapping Template"
**What:** JSON file generated by Discovery Engine  
**Contains:** Every add-on config, where it's stored (GUID/path), how to update it, validation rules  
**Why:** Foundation for safe Provisioning — can't automate what you haven't mapped  
**See:** ProvisioningAI_PRD_v1.0.md section 6.5 (comprehensive explanation with examples)

### GUID-First Lookup
**What:** Use GUIDs as primary key instead of property IDs  
**Why:** GUIDs are stable across vault clones; IDs might shift  
**Result:** Safe, deterministic updates (can't accidentally update wrong field)  
**See:** GUID_MAPPING_INVESTIGATION.md (investigation framework)

### Plan/Apply Pattern
**What:** Generate plan (show what will change) → Approval → Execute → Test → Rollback if needed  
**Why:** Safety — never blindly update production without review  
**Result:** Zero surprises, complete audit trail, instant rollback if needed  
**See:** COMPLETE_VISION.md (visual flow of plan/apply)

### Vault Reuse Architecture
**What:** Clone template vault for each customer → GUIDs stay same → Customize add-on configs → Deploy  
**Why:** Reusing vault structure saves time (don't rebuild from scratch)  
**Automation:** Discover configs once → Automate customization infinitely  
**See:** COMPLETE_VISION.md (section "Why This Approach is Perfect")

## 💡 Key Insights (The Foundation of Everything)

1. **"You cannot safely automate what you have not fully mapped"**
   - Discovery is mandatory, not optional
   - Mapping template is the key to automation
   - See: ARCHITECTURAL_DEPENDENCY.md

2. **"Vault reuse is good if we automate the customization"**
   - Reusing vaults saves time (don't rebuild structure)
   - Automating customization saves weeks
   - See: COMPLETE_VISION.md

3. **"GUIDs are stable, IDs are not"**
   - If GUIDs are queryable → Use GUID-first lookup
   - If not → Use name-based lookup with GUID verification
   - See: GUID_MAPPING_INVESTIGATION.md

4. **"Plan/Apply makes it safe"**
   - Generate plan (what will change) before executing
   - Require operator approval
   - Maintain rollback capability

5. **"Multi-view workflow visualization creates trust"**
   - Animation supports fast business understanding
   - M-Files original view supports source validation
   - Metadata and JSON views support technical verification and export
   - Audit every change
   - See: COMPLETE_VISION.md, INVESTIGATION_AND_AUTOMATION_STRATEGY.md
