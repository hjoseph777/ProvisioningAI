Translation Plan Renderer

Reads a TranslationPlan JSON (as produced by ProvisioningAI.Workflow/Translation, unmodified) and renders it two ways, side by side: the original Mermaid diagram (via Mermaid.js, unmodified) and a schematic M-Files-style diagram built directly from the plan's own resolved field values — never re-derived from the Mermaid source. Read-only demonstration; no vault access, no writes.
